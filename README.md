# Difficult Alarmclock - Turn your Unix box into a music clock that sucks less
[see the blog post (zh_CN)](https://dongdigua.github.io/alarm_clock)  
requirement: `mpg123`, `python-crontab`, a cgi webserver

## Usage

1. put mp3 in `data` directory
2. put alarmclock.py (edit the constant) in your cgi directory
3. BOOM

if you are unfamilliar with crontab syntax, visit [crontab.guru](https://crontab.guru)
